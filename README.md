# Tauri Android Init

将Tauri 项目配置为 Android 开发环境，覆盖从初始化到签名的完整流程：

- `tauri android init` 初始化 Android 项目
- Gradle / NDK 链接器错误排查
- 设备白屏 / WebView 调试（chrome://inspect）
- Vite 前端热更新（HMR）+ 真机联调配置
- APK 发布签名配置与构建

> 适用于 `npm create tauri-app@latest` 创建的 Tauri v2 项目。

## 安装

```bash
git clone https://github.com/Zephyruston/tauri-android-init.git ~/.claude/skills/tauri-android-init
```

Then use it by typing `/tauri-android-init` in Claude Code.
